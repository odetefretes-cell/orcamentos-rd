# ⛔ AGUARDANDO OS LAYOUTS OFICIAIS DA OPHOS

Colocar NESTA pasta os arquivos de layout do **Integrador OPHOS** (versão 5.24) baixados
do suporte (https://www.ophos.com.br/suporte/integrador/): manuais do TXT padrão OPHOS
(CT-e, MDF-e 2.08, CIOT), XML SEFAZ e/ou documentação de Web Services.

**Nenhum builder (`src/builders/`) pode ser escrito antes desses arquivos chegarem** —
regra da arquitetura (§2): parser/builder nasce do layout oficial, nunca de suposição.

Como subir os arquivos (GitHub, pelo navegador):
1. Abrir https://github.com/odetefretes-cell/orcamentos-rd
2. Trocar a branch para `claude/automate-transport-contract-form-tgvad2`
3. Navegar até `obs-fiscal-service/docs/ophos-layouts/`
4. **Add file → Upload files** → arrastar os arquivos → Commit changes
